# Фронтенд ZAL

Владелец Makhkets, ветка frontend. Стартовый React/Vite каркас; продукт реализовать по ../../docs/prompts/frontend.md.

Из корня запустить python3 scripts/mock_api.py. Здесь выполнить npm ci и npm run dev. Vite проксирует /api на 8000.

Дизайн-токены уже в src/design-tokens.css. Геометрия и API описаны в ../../contracts/openapi.json. Зависимости Three.js добавить при выполнении F3, сохранив package-lock.json.
