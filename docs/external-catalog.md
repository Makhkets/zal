# Внешний каталог фильмов

На главной странице блок «Фильмы и трейлеры» получает реальные сведения через официальный Apple iTunes Search API. Основная афиша ZAL остаётся отдельной: результаты внешнего поиска не создают кинотеатры, сеансы, цены или билеты и не означают партнёрство с кинотеатрами.

## Настройка

В серверном окружении нужен `ENABLE_EXTERNAL_MEDIA_NETWORK=1`. Новых API-ключей не требуется. При выключенной сети, превышении лимита или ошибке источника интерфейс показывает соответствующее состояние; подборка других фильмов вместо ответа не подставляется. Ранее полученные данные доступны до истечения срока кеша.

`GET /api/v1/catalog/external/search?q=Dune` возвращает `status`, `storefront`, `sources_queried` и `items`. Поддержаны статусы `ok`, `disabled`, `unavailable`, `rate_limited`. Карточка содержит название, год даты релиза из источника, жанр, длительность, постер, ссылку в iTunes и собственное видеопревью, если оно предоставлено источником. Рейтинги и отзывы не выдумываются. Импорт сеансов через публичный API отключён до появления авторизации администратора.

Используется витрина США, явно обозначенная в интерфейсе: доступность покупки зависит от региона магазина, названия и описания могут быть английскими. Для нескольких популярных русских названий и фамилии Нолан есть точные поисковые алиасы; для остальных лучше оригинальное название. Это поиск по ответу источника, а не полная локальная копия каталога.

Apple документирует фильтры `media=movie` и `entity=movie`, но при проверке 7 ноября 2026 они возвращали пустой результат для известных доступных фильмов. Адаптер использует документированный поиск по всем типам, затем принимает только `kind=feature-movie` и удаляет дубликаты по `trackId`. Возвращается до 12 фильмов из первых 40 результатов источника, по три карточки на странице интерфейса.

Метаданные кешируются в SQLite на шесть часов; запросы ограничены 18 обращениями в минуту на процесс API. Параллельные одинаковые запросы используют общий кеш. Превью не скачиваются на сервер и не кешируются приложением: браузер воспроизводит оригинальный HTTPS URL Apple. Ссылки проходят проверку разрешённых доменов. Рядом с каждым превью и карточкой есть прямая ссылка в iTunes и официальный значок магазина.

## Проверка

`apps/api/tests/test_external_catalog.py` проверяет фильтрацию реальных фильмов, точное соответствие превью, дедупликацию, кеш, совместные запросы, ограничение частоты, отключённую сеть, ошибки источника, отсутствие выдуманной подстановки и небезопасные URL. Отдельные проверки запрещают выдавать чужой ролик за трейлер фильма из афиши: для фильма без явной привязки `/trailer` и `/enrichment` возвращают 404. В расчёте акустики используется отдельно названный тестовый ролик Sintel.

В браузере проверены живой поиск Dune, постеры, три результата на странице, переключение страницы, пустой поиск, оригинальное видеопревью, Escape и возврат фокуса после диалога, тёмная и светлая темы и экран 390 px. Доступность внешнего сервиса и видео в каждой сети или стране не гарантируется.
