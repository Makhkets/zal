# Приёмка перед демонстрацией

Каждый пункт отмечать после фактической проверки. Автоматические проверки стартового комплекта проверяют контракт и мок, а не будущую production-реализацию.

## Основной путь

- [ ] На чистом устройстве открываются два кинотеатра и будущие сеансы.
- [ ] Другой кинотеатр меняет список сеансов; смена сеанса сбрасывает старое место.
- [ ] Свободное, забронированное и купленное места различимы.
- [ ] Цены 350/550/900 ₽ приходят с сервера, клиент не может подменить сумму.
- [ ] Ряд 1 место 3, ряд 6 место 12, ряд 10 диван 7 дают разные 3D-виды.
- [ ] Случайное место тоже работает; 3D соответствует его точке на SVG.
- [ ] Из 3D можно вернуться, выбор и цена сохранены.
- [ ] Checkout создаёт заказ и переводит в СБП.
- [ ] До CONFIRMED билет недоступен; редирект не делает заказ оплаченным.
- [ ] После оплаты билет содержит верные фильм, зал, время, место и цену.
- [ ] QR открывает проверку билета на другом устройстве, email не виден.
- [ ] Вторая вкладка видит купленное место занятым.
- [ ] Перезапуск API не теряет покупку или билет.

## Защита покупки

- [ ] Два одновременных заказа на одно место: один успешен, другой получает 409.
- [ ] Повтор с одним Idempotency-Key возвращает тот же order.id.
- [ ] Тот же ключ с другим телом даёт IDEMPOTENCY_CONFLICT.
- [ ] Таймаут POST к Platega не создаёт второй платёж.
- [ ] Два одинаковых CONFIRMED оставляют один билет.
- [ ] Callback без/с неверным секретом отклоняется.
- [ ] Неверная сумма, валюта или привязка transactionId не выпускает билет.
- [ ] Callback до сохранения ответа создания обработан через проверенную сверку.
- [ ] Старый CANCELED не отменяет paid.
- [ ] Банк недоступен после истечения таймера: место не продаётся повторно вслепую.
- [ ] Возврат/спор меняет статус проверки билета.
- [ ] Чужой access_token не открывает заказ.
- [ ] Production не содержит /__mock/confirm или ручного paid.

## UX и бонусы

- [ ] Экран 390 px: кнопки видны, схема увеличивается, нижняя панель не перекрывает выбор.
- [ ] Быстрые клики, перезагрузка checkout, потеря сети дают понятное восстановление.
- [ ] Все экраны имеют один стиль из PDF; контраст и клавиатура проверены.
- [ ] При отсутствии WebGL остаётся покупка и понятное сообщение.
- [ ] Звук меняется слева/справа и спереди/сзади, не включается сам.
- [ ] Сравнение A/B использует реальные точки двух мест и позволяет выбрать одно.

## Развёртывание и показ

- [ ] Публичный HTTPS открывается на телефоне вне локальной сети.
- [ ] Callback URL доступен Platega и не ломает другой проект мерчанта.
- [ ] SQLite на постоянном диске; один инстанс; рестарт проверен.
- [ ] Реальная ручная оплата пройдена, время и результат записаны без секретов.
- [ ] Есть один заранее оплаченный билет как резерв на задержку банка.
- [ ] Слайды сохранены локально, живая демонстрация отрепетирована.
- [ ] В презентации нет заявлений о функциях, которые остались только в плане.
